# 点云数据处理与打磨深度计算流程

## 1. 文档目的

本文说明系统如何从 Left、Right 两台廓形仪采集的三维点云中提取轨面代表廓形，并计算各打磨角度对应的最终打磨深度。

整个计算分为两条相互独立的分支：

1. **常规打磨深度分支**：使用多条截面的平均代表廓形，反映轨面整体磨耗情况。
2. **最大掉块深度分支**：分别查找 Left、Right 点云中最严重的局部掉块截面，防止平均处理掩盖局部深坑。

最终打磨深度取两条分支中更大的结果。

## 2. 坐标与基本概念

点云中的坐标含义如下：

- `X`：钢轨横向位置。
- `Y`：小车或钢轨前进方向。
- `Z`：轨面高度。

点云原始点表示为 `(X, Y, Z)`。提取为二维轨面廓形后，`RailProfilePoint` 中的坐标含义为：

- `RailProfilePoint.X`：原始点云的横向坐标 `X`。
- `RailProfilePoint.Y`：原始点云的高度坐标 `Z`。

系统按照设备配置将廓形仪标记为 `Left` 或 `Right`，两侧分别使用对应的镜像、旋转、平移和裁切参数。

## 3. 点云采集与数据入口

### 3.1 加载采集参数

开始测量前，系统加载点云采集参数，包括小车速度、单次测量总条数和计算帧率等，并将相关参数写入点云设备。

如果采集参数不存在或不合法，系统终止本次计算并提示用户先完成配置。

### 3.2 在线采集点云

廓形仪首先采集 Range 深度图，然后通过 SDK 的 `MapDepthToPointCloud` 功能转换为三维点云 `(X, Y, Z)`。

系统优先直接处理内存中的在线点云，避免不必要的文件读写。如果在线读取或在线代表廓形提取失败，则自动将点云导出为 CSV，再从 CSV 解析坐标并继续处理。

### 3.3 无效点处理

三维坐标均为 `0` 的点 `(0, 0, 0)` 被视为无效点，不参与后续计算。公共预处理还会统一过滤以下非有限坐标：

- `NaN`：Not a Number，表示无法得到有效数值的结果。
- `PositiveInfinity`：正无穷大。
- `NegativeInfinity`：负无穷大。

这些值不能参与排序、插值、拟合或残差计算，否则可能使后续结果全部变成无效数值。

## 4. 原始点云方向校正

Left、Right 点云进入算法后，系统加载当前轨型对应的手动配准参数，并执行以下处理：

1. 根据侧别和 `IsMirrored` 参数决定是否沿 X 方向镜像。
2. 计算有效原始点在 X/Z 平面上的质心。
3. 围绕质心旋转 X/Z 坐标，Y 坐标保持不变。
4. 后续生成二维廓形后，再应用 `Dx`、`Dy` 平移和 `XMin`、`XMax` 裁切。

配准参数的作用是把两台设备采集的点云统一到标准轨面的坐标系中。缺少有效配准参数时，带侧别的代表廓形提取不会自动猜测对齐方式，而是直接报告错误。

同一侧点云只执行一次有效点过滤、配准参数加载、方向校正和 Y 分组。生成的只读截面集合由常规打磨深度分支和最大掉块深度分支顺序复用。CSV 输入也只解析一次文件，再进入相同的公共预处理流程。

## 5. 常规打磨深度分支

### 5.1 按 Y 拆分轨面截面

系统按照前进方向 `Y` 对点云分组。Y 坐标相近的点被认为属于同一条横向轨面截面，当前分组容差为 `0.25 mm`。

每条截面内部按照 X 坐标排序。同一 X 位置存在多个点时，将这些点的 X、Z 分别取平均，合并成一个二维点。

一条有效截面至少需要两个不同的 X 位置，并且必须具有有效的 X 覆盖范围。整个点云至少需要形成 5 条有效截面，否则系统认为点云质量不足，不继续生成平均代表廓形。

### 5.2 确定公共 X 范围

不同截面的横向覆盖范围可能不同。例如：

```text
截面 A：X = 0.0 ～ 70.0
截面 B：X = 1.0 ～ 69.5
截面 C：X = 0.5 ～ 68.0
```

系统只使用所有有效截面共同覆盖的区域，因此公共范围为：

```text
X = 1.0 ～ 68.0
```

这样可以保证公共范围内每个 X 位置都能从所有有效截面获得对应高度，避免在没有数据的区域进行外推。

### 5.3 建立统一 X 网格

各截面的实际采样位置通常不完全一致。系统先计算每条截面的平均 X 采样间距，再取所有截面代表间距的中位数，作为统一 X 网格的步长。

例如统一网格可能为：

```text
X = 1.0、1.2、1.4、1.6、……、68.0
```

### 5.4 对 Z 进行线性插值

对于统一网格上的某个 X，如果原始截面没有正好采集到该位置，系统使用左右两个相邻点估算对应的 Z：

```text
Z = Z1 + (Z2 - Z1) × (X - X1) / (X2 - X1)
```

这里的插值是在一条截面内部沿 X 方向进行，不是在不同 Y 截面之间插值。

线性插值使所有截面都具有相同的 X 采样位置，之后才能在同一 X 位置比较和平均高度。

### 5.5 同一 X 位置计算去异常平均 Z

系统收集所有有效截面在同一个网格 X 位置插值得到的 Z。

当 Z 数量少于 5 个时，直接计算算术平均值；当 Z 数量不少于 5 个时，使用中位数和 MAD 识别异常高度：

```text
Z中位数 = median(Z)
偏差i = |Zi - Z中位数|
MAD = median(偏差)
稳健标准差 = 1.4826 × MAD
过滤阈值 = max(0.001, 3 × 稳健标准差)
```

只保留满足下式的 Z：

```text
|Zi - Z中位数| ≤ 过滤阈值
```

最后对保留的 Z 求平均，得到该 X 位置的 `AverageZ`。这一步可以防止少数反光飞点或高度跳变把平均轨面明显拉高或拉低。

所有 `(X, AverageZ)` 点按 X 排列后，形成初始平均代表廓形。

### 5.6 局部拟合残差与 MAD 离群过滤

初始平均代表廓形生成后，系统继续检查其中是否存在偏离局部轨面走势的孤立点。

对代表廓形中的每一个点执行以下步骤：

1. 按 X 顺序选择当前点左右的局部邻点。
2. 暂时排除当前点，避免异常点影响自身的拟合结果。
3. 使用邻点进行 PCA 局部直线拟合。
4. 计算当前点到局部拟合直线的最短距离，将该距离作为局部拟合残差。

局部窗口大小根据代表点总数自动调整：

```text
窗口大小 = min(15, max(5, 代表点数 / 5))
```

系统尽量保证至少有 6 个邻点参与拟合。PCA 直线拟合能够处理接近垂直的局部轨面，避免普通 `Z = aX + b` 拟合在垂直区域失效。

获得所有点的局部残差后，再通过 MAD 计算过滤阈值：

```text
残差中位数 = median(residual)
偏差i = |residuali - 残差中位数|
MAD = median(偏差)
稳健标准差 = 1.4826 × MAD
过滤阈值 = max(0.001, 2.2 × 稳健标准差)
```

偏差超过阈值的点会被删除。过滤最多执行两轮，使第一轮删除明显飞点后，第二轮能够基于更干净的廓形重新判断。

每轮至少保留原有点数的 40%。如果按阈值过滤后剩余点过少，则改为保留残差最小的前 40%，避免异常数据将整条廓形清空。

这一步只删除离群点，不会修改保留点的坐标，也不会把真实轨面强行拉直。

### 5.7 平移、裁切与左右合并

离群过滤完成后，系统应用对应侧别的 `Dx`、`Dy` 平移参数，并按照最终 X 坐标执行 `XMin`、`XMax` 裁切。

Left、Right 分别得到平均代表廓形后，将两侧代表点合并，形成用于常规打磨深度计算的完整代表廓形。

### 5.8 根据角度计算代表廓形的单位法向支撑值

对每一个打磨角度 `angle`，使用单位法向表达式：

```text
c = Z*cos(angle) - X*sin(angle)
```

代表廓形中的每个点 `(Xi, Zi)` 都会产生一个候选支撑值：

```text
ci = Zi*cos(angle) - Xi*sin(angle)
```

该表达式直接表示点在单位法向上的投影距离，在 `90°` 时退化为 `c = -X`，不会出现 `tan(90°)` 数值发散。

系统使用顶部候选值计算唯一的 `c_profile`，当前选取数量为：

```text
topCount = max(1, 代表点数 / 200)
```

随后对最大的 `topCount` 个候选 c 求平均：

```text
c_profile = 顶部 topCount 个 ci 的平均值
```

该规则通常描述为“取前 0.5% 最大候选值的平均”。由于使用整数除法，代表点少于 400 个时 `topCount` 仍为 1，此时实际退化为取单个最大候选值。

### 5.9 计算标准轨面的单位法向支撑值

系统在当前标准轨面分段圆弧上求最大单位法向投影：

```text
c_standard = max(Z_standard*cos(angle) - X_standard*sin(angle))
```

其物理含义是标准轨面在当前打磨方向上的接触位置。

### 5.10 计算单组常规打磨深度

当前角度的常规打磨深度为：

```text
D_regular = |c_profile - c_standard|
```

系统对所有配置角度重复上述计算，每个角度得到一个常规打磨深度。

如果测量流程包含多组 Left、Right 采集，则每组先独立计算一次常规深度，测量结束后再对相同角度的所有组求平均：

```text
平均常规深度 = 各组 D_regular 之和 / 有效测量组数
```

## 6. Left/Right 最大掉块深度分支

平均代表廓形能够降低随机噪声，但也可能把只出现在某一条截面上的严重掉块平均掉。因此系统同时直接分析 Left、Right 原始点云中的每条截面。

### 6.1 分侧拆分原始截面

Left、Right 点云分别执行方向校正，然后按照 `0.25 mm` 的 Y 容差拆分成多条二维 `(X, Z)` 截面。

每条截面内部按 X 排序；同一 X 位置出现多个点时，对 X、Z 分别取平均。随后应用该侧的平移和 X 范围裁切参数。

Left 和 Right 全程独立分析，不进行纵向截面匹配。

### 6.2 第一次删除低于标准轨面最低高度的点

每条截面完成方向校正、平移和 X 裁切后，系统先确定该截面在标准定义域内的实际横向范围 `[X_section_min, X_section_max]`，再根据当前选择的 50kg/m 或 60kg/m 标准轨面计算此区间内的最低高度 `Z_section_min`。超出标准定义域 `[-35.4,35.4]` 的 X 不参与阈值计算。随后执行：

```text
保留 Zi >= Z_section_min 的点
删除 Zi < Z_section_min 的点
```

这里比较的是配准后点云的高度 `Z`；三维点云中的 `Y` 表示前进方向，不参与最低高度筛选。该筛选用于阻止极低异常点参与残差计算。删除位置作为硬分隔符，将同一条原始截面拆成多个有效片段；删除点两侧不会重新拼接，后续连续负残差判断只能在单个片段内部执行。低于最低高度的点无论连续数量多少都只视为无效数据，不参与掉块深度或 `3 mm` 超限判断。

### 6.3 根据第一次有效片段范围执行第二次筛选

第一次筛选后，系统先排除少于 3 点的片段，再从剩余片段的全部标准定义域内点重新确定实际横向范围，并计算第二个标准轨面区间最低高度。随后对每个第一次有效片段分别执行相同的 `Z >= Z_section_min` 判断，固定复筛一次；不会循环执行第三次筛选。

第二次筛选不会跨第一次删除形成的缺口连接点；两轮删除位置都作为硬分隔符，第二次筛选后少于 3 点的片段再次排除。最终片段保留配准后的原始 X/Z，不执行三点中位滤波或残差 Z 重构，片段首尾点不会被额外删除。

### 6.4 计算最终片段相对标准轨面的残差

对第二次筛选后有效域内的每个原始点计算：

```text
ri = Zi - RailSurfaceFun(Xi)
```

残差含义如下：

- `ri > 0`：测量点位于对应标准轨面之上。
- `ri < 0`：测量点位于对应标准轨面之下。
- `ri ≈ 0`：测量点接近标准轨面。

### 6.5 计算单条截面的最大向下掉块量

系统只把严格小于 `0` 的原始残差视为测量廓形低于标准轨面的向下缺失。在同一个有效片段内按 X 顺序至少连续出现 3 个负残差点时，该段才构成有效掉块区域；连续 1～2 个负残差点不构成掉块，不同片段的负残差不会合并计数。

单条截面的最大掉块量定义为所有有效向下区域中的最深缺失：

```text
D_drop = max(0, -min(r_valid))
```

例如原始残差为：

```text
0.15、-0.20、-0.50、-0.40、0.10
D_drop = -(-0.50) = 0.50 mm
```

如果原始残差全部大于等于 `0`，或不存在连续 3 个负残差点，则该截面没有有效向下掉块，不参与候选选择。正向凸起不会扩大 `D_drop`。

计算完成后执行异常数据判断：

```text
D_drop > 3 mm：判为异常廓形，不参与后续选择
D_drop <= 3 mm：保留为有效候选廓形
```

因此 `3 mm` 本身属于有效边界。某侧没有向下掉块时，该侧最大掉块廓形为空、附加深度按 `0` 处理，常规深度计算继续执行；如果检测到向下候选但全部 `D_drop > 3 mm`，系统仍会报告异常数据。

### 6.6 每侧选择最严重截面

系统分别比较 Left 的所有截面和 Right 的所有截面：

```text
Left最大掉块截面 = Left中 D_drop 最大的截面
Right最大掉块截面 = Right中 D_drop 最大的截面
```

如果包含多组测量，系统还会在所有测量组之间继续比较。测量结束时，Left、Right 各自只保留有效候选中 `D_drop` 最大的那条截面。

需要注意：`D_drop` 只用于选择最严重截面，并不直接作为最终的 Left/Right 掉块深度。

最大掉块对比窗口按第二次筛选后点集的 X 顺序绘制原始折线，不使用 Catmull–Rom 平滑，避免陡峭区域的样条过冲产生假尖刺；普通代表廓形窗口仍保留平滑显示。

### 6.7 计算每个角度的 Left/Right 掉块深度

选中最大掉块截面后，系统使用第二次最低高度筛选后保留的原始 X/Z 廓形进行标准对齐和各角度计算。

掉块角度先按设备侧别分配：

```text
angle > 0：只使用 Left 最大掉块廓形
angle < 0：只使用 Right 最大掉块廓形
angle = 0：Left、Right 都计算并取较大值
```

匹配侧使用与常规分支相同的单位法向支撑值：

```text
c_standard = 标准轨面的法向支撑值
c_left = Left标准对齐后最大掉块廓形的法向支撑值
c_right = Right标准对齐后最大掉块廓形的法向支撑值
```

单侧附加打磨深度为：

```text
D_left = max(0, c_left - c_standard)
D_right = max(0, c_right - c_standard)
```

使用 `max(0, ...)` 而不使用绝对值，只把测量廓形法向支撑值高于标准轨面的部分计为打磨深度。不匹配当前角度的设备侧直接按 `0` 处理。

如果某侧没有可用的最大掉块廓形，则该侧对应角度的附加深度按 `0` 处理。

## 7. 最终打磨深度汇总

对于每一个打磨角度，系统已经得到：

```text
平均常规深度
Left掉块深度
Right掉块深度
```

最终打磨深度为：

```text
D_final = max(平均常规深度, D_left, D_right)
```

也可以分两步理解：

```text
D_defect = max(D_left, D_right)
D_final = max(平均常规深度, D_defect)
```

例如某个角度的结果为：

```text
平均常规深度 = 0.55 mm
Left掉块深度 = 0.72 mm
Right掉块深度 = 0.48 mm
```

则：

```text
D_final = max(0.55, 0.72, 0.48)
        = 0.72 mm
```

这种汇总方式同时考虑整体磨耗和局部最严重掉块，避免平均代表廓形将局部缺陷稀释。

## 8. 打磨次数换算

主界面测量流程在得到最终打磨深度后，按照每次打磨 `0.05 mm` 换算打磨次数：

```text
打磨次数 = ceil(D_final / 0.05)
```

例如：

```text
D_final = 0.72 mm
打磨次数 = ceil(0.72 / 0.05)
         = ceil(14.4)
         = 15 次
```

系统对每个固定打磨角度分别计算最终深度和打磨次数，用户确认后再将结果写入 PLC 对应的打磨次数区域。

## 9. 关键公式汇总

```text
角度对应单位法向支撑值：
c = Z*cos(angle) - X*sin(angle)

代表点候选支撑值：
ci = Zi*cos(angle) - Xi*sin(angle)

代表廓形支撑值：
c_profile = 顶部 topCount 个 ci 的平均值
topCount = max(1, 代表点数 / 200)

常规打磨深度：
D_regular = |c_profile - c_standard|

截面残差：
ri = Zi - RailSurfaceFun(Xi)

单截面最大向下掉块量：
D_drop = max(0, -min(r_valid))，其中 r_valid 属于至少连续 3 点的负残差区域

Left/Right附加打磨深度：
D_left = max(0, c_standard - c_left)，仅 angle >= 0
D_right = max(0, c_standard - c_right)，仅 angle <= 0

最终打磨深度：
D_final = max(平均常规深度, D_left, D_right)

打磨次数：
GrindingTimes = ceil(D_final / 0.05)
```

- `Services/Rail/Processing/RepresentativeProfilePointProcessor.cs`：局部拟合残差与 MAD 离群过滤。
- `Services/Rail/MaximumDropProfileService.cs`：最大掉块截面的两次区间最低高度筛选和连续向下缺失分析。
- `Services/Rail/Core/StandardRailProfileSolver.cs`：标准轨面函数、标准 b 和代表廓形 b 的求解。
- `Services/RailSurfaceService.cs`：常规深度与单侧掉块附加深度计算入口。
- `Services/Measurement/MeasurementParameterService.cs`：多组深度汇总、最终深度和打磨次数计算。

## 11. 流程图节点逐项对照讲解

本节按照流程图从上到下的顺序，对每一个处理节点和判断节点进行解释。

### 11.1 点云采集和公共预处理节点

#### 节点 1：开始——读取点云采集参数与设备侧别

系统先读取小车速度、采集条数和帧率等参数，同时根据设备序列号配置确定当前廓形仪属于 Left 还是 Right。采集参数决定设备怎样采集点云，侧别决定后续使用哪一组配准参数。

#### 节点 2：采集 Range 深度图

廓形仪先返回 Range 深度图。深度图记录传感器采样位置对应的距离信息，此时数据还不是算法直接使用的三维 `(X, Y, Z)` 坐标。

#### 节点 3：`MapDepthToPointCloud` 转换三维点云

系统调用点云 SDK，将 Range 深度图映射成三维点云。转换完成后，每个有效采样点具有横向位置 X、前进方向位置 Y 和高度 Z。

#### 节点 4：在线点云是否可直接处理

这是一个判断节点。系统优先尝试直接读取并处理内存点云：

- 如果在线点云读取成功、点数大于 0，并且代表廓形提取成功，则进入“使用内存点云”。
- 如果在线读取或在线提取失败，则进入 CSV 回退流程。

#### 节点 5：使用内存点云

在线点云可用时，系统直接将内存中的点集交给代表廓形服务和最大掉块服务，不要求先落盘再读取。测量归档功能仍可以异步保存点云，但归档不阻塞当前计算。

#### 节点 6：导出 CSV 并重新解析点云

在线处理不可用时，系统重新执行点云导出，将数据写入 `Log` 目录下的 CSV，然后由 CSV 解析器识别表头、分隔符和 X/Y/Z 列，重新构造三维点集。

#### 节点 7：过滤零点、NaN、Infinity 等无效点

`(0, 0, 0)` 通常代表设备未产生有效距离数据，因此被删除。最大掉块分支还会删除包含 `NaN`、正无穷或负无穷的坐标。无效点不能参与排序、插值和拟合。

#### 节点 8：按 Left/Right 加载配准参数

系统根据设备侧别加载当前轨型对应的镜像、旋转、平移和裁切参数。Left、Right 参数相互独立，不能混用。

#### 节点 9：原始点镜像、旋转和方向校正

系统先根据侧别和配置决定是否镜像 X，再围绕原始有效点的 X/Z 质心执行旋转，Y 保持不变。这一步将设备坐标方向校正到标准轨面坐标方向。平移和裁切在二维截面生成后执行。

完成公共预处理后，同一份已过滤、方向校正并按 Y 分组的只读截面集合同时进入常规深度分支和最大掉块深度分支，不再由两条分支分别重复排序和分组。

### 11.2 常规打磨深度分支节点

#### 节点 10：按 Y 分组为多条轨面截面

系统按前进方向 Y 对点云分组，Y 相差不超过 `0.25 mm` 的相邻点归入同一条横向截面。每条截面在二维上表现为一系列 `(X, Z)` 点。

#### 节点 11：有效截面是否不少于 5 条

这是常规分支的数据质量判断：

- 少于 5 条时，认为数据不足以形成稳定平均结果，终止当前代表廓形计算并报告异常。
- 不少于 5 条时，继续计算公共 X 范围。

#### 节点 12：终止并报告点云质量异常

该节点表示算法不会在截面数量严重不足时静默输出结果。调用方会收到代表廓形提取异常，从而避免把不可靠深度写入后续流程。

#### 节点 13：计算各截面的公共 X 范围

系统取所有有效截面 X 范围的交集。交集以外的区域不能保证每条截面都有数据，因此不会用于平均，也不会进行外推。如果交集宽度无效，同样终止计算。

#### 节点 14：建立统一 X 网格

系统统计每条截面的典型 X 间距，再取截面间的中位值作为统一步长，在公共 X 范围内建立一组固定 X 位置。统一网格解决不同截面采样位置不一致的问题。

#### 节点 15：各截面对 Z 进行线性插值

对于统一网格中的某个 X，系统在每条截面内找到左右相邻点，并根据两点间的直线比例估算 Z。该插值仅在 X 公共范围内进行，不进行范围外推。

#### 节点 16：同一 X 位置计算去异常平均 Z

系统收集所有截面在相同网格 X 位置的插值 Z。数量不少于 5 时先使用中位数和 MAD 删除异常 Z，再对剩余 Z 求平均；数量少于 5 时直接平均。每个 X 最终只输出一个 `AverageZ`。

#### 节点 17：局部拟合残差与 MAD 离群过滤

系统检查初始代表廓形中的每个点是否符合附近点的局部走势。当前点被暂时排除，邻点通过 PCA 拟合局部直线，当前点到直线的距离作为残差。残差明显超过 MAD 阈值的点被删除，过滤最多执行两轮。

#### 节点 18：应用 `Dx/Dy` 平移及 X 范围裁切

代表廓形去除离群点后，系统按照侧别配置执行横向和高度平移，再按最终 X 坐标裁切。该步骤把代表廓形放到标准轨面坐标系中的正确位置，并排除不参与打磨计算的区域。

#### 节点 19：合并 Left/Right 平均代表廓形

Left 和 Right 各自产生一组经过配准的代表点。系统将两组点合并为一条覆盖左右轨面的完整代表廓形，用于常规深度计算。这里是点集合并，不是按 Y 对左右原始截面进行配对。

#### 节点 20：输入打磨角度 `angle`

系统按配置的角度列表逐个计算。一个角度对应砂轮或接触线的一种方向，因此每个角度会得到独立的深度结果。

#### 节点 21：计算单位法向量

角度从度转换为弧度后，使用 `(-sin(angle), cos(angle))` 作为单位法向量。该表示在 `90°` 时仍然有限。

#### 节点 22：标准轨面求法向支撑值 `c_standard`

系统求标准轨面各分段圆弧沿单位法向量的最大投影，该值表示当前角度下的目标接触位置。

#### 节点 23：代表廓形计算候选值 `ci = Zi*cos(angle) - Xi*sin(angle)`

一条代表廓形包含多个离散点，每个点都会产生一个法向投影候选值。

#### 节点 24：取前 0.5% 最大候选值的平均得到 `c_profile`

系统从候选 c 中选择顶部值并求平均，得到当前角度唯一的测量廓形支撑值。实际数量为 `max(1, 点数/200)`；点数不足 400 时会退化为取单个最大值。

#### 节点 25：计算常规深度

测量代表廓形与标准轨面的法向支撑值差为：

```text
D_regular = |c_profile - c_standard|
```

这里使用绝对值，使整体高低偏差都转换成非负的常规打磨深度。

### 11.3 最大掉块深度分支节点

#### 节点 26：Left/Right 原始点云分别按 Y 拆分截面

最大掉块分支不使用平均代表廓形，而是保留原始点云中的每条截面。Left、Right 分别分组和分析，避免局部掉块在多截面平均中被稀释。

#### 节点 27：截面点按 X 排序、去重并平移裁切

每条截面先按 X 排序。同一 X 位置的多个点通过平均合并，再应用对应侧别的平移和裁切参数，使其能够与标准轨面在同一坐标系内比较。

完成配准后，系统根据每条截面自己的 X 范围计算标准轨面区间最低高度，并删除高度 `Z` 小于该值的点。该筛选不使用代表前进方向的三维 `Y` 坐标；删除位置将截面拆分为独立有效片段，后续筛选不会跨片段重新连接。

#### 节点 28：按第一次有效片段范围执行第二次筛选

第一次筛选先排除少于 3 点的片段，再按剩余点的实际 X 范围重算标准轨面区间最低高度，并对每个已有片段固定复筛一次。第二次删除继续形成硬边界，复筛后少于 3 点的片段再次排除；最终片段保留原始 X/Z 和首尾点，不执行残差中位滤波、Z 重构或第三次筛选。

#### 节点 29：计算标准轨面残差 `r = Z - RailSurfaceFun(X)`

最终保留点的 Z 减去相同 X 位置的标准轨面高度。残差反映测量点相对标准轨面的高低，而不是测量点的绝对 Z。

#### 节点 30：计算单截面向下掉块量 `D_drop = max(0, -min(r_valid))`

系统逐片段扫描原始残差，只接受同一片段内至少连续 3 个 `r < 0` 的向下区域，并取这些有效区域中的最深负残差作为 `D_drop`。完全高于标准轨面的截面没有掉块候选。若 `D_drop > 3 mm`，该截面判为异常数据并排除；`D_drop = 3 mm` 时仍为有效候选。

#### 节点 31：每侧选择 `D_drop` 最大的截面

Left 内部从包含连续向下缺失且未超过 `3 mm` 的有效候选中选择一条最严重截面，Right 同样处理。如果有多组测量，每侧还会跨测量组继续比较。某侧不存在候选时按 `0` 深度继续流程。该节点只负责定位候选截面，`D_drop` 不直接作为最终附加深度。

#### 节点 32：按角度匹配侧别并计算 `c_side` 与 `c_standard`

正角度只计算 Left，负角度只计算 Right，`0°` 同时计算两侧。对匹配侧的最大掉块截面使用与常规分支相同的单位法向支撑值算法，未匹配侧按 `0` 处理。

#### 节点 33：计算单侧附加深度

左右两侧分别计算：

```text
D_left = max(0, c_left - c_standard)
D_right = max(0, c_right - c_standard)
```

只保留测量廓形法向支撑值高于标准轨面的部分；测量廓形不高于标准时该角度按 `0` 处理。

#### 节点 34：计算掉块深度 `D_defect`

当前角度的左右附加深度取较大值：

```text
D_defect = max(D_left, D_right)
```

这样任意一侧存在严重局部掉块时，都能进入最终深度判断。

### 11.4 多组测量与最终结果节点

#### 节点 35：是否包含多组测量

这是结果汇总方式的判断节点。调试窗口的一次 Left/Right CSV 计算通常属于单组计算；主界面测量运行可能在小车行进过程中累计多组 Left/Right 测量。

#### 节点 36：单组测量的最终打磨深度

只有一组测量时，不需要对常规深度求跨组平均，直接计算：

```text
D_final = max(D_regular, D_left, D_right)
```

#### 节点 37：多组常规深度取平均，掉块廓形取每侧最深结果

包含多组测量时：

- 相同角度的常规深度累加后除以有效组数，得到平均常规深度。
- Left 在所有组的有效候选中保留 `D_drop` 最大的截面。
- Right 在所有组的有效候选中保留 `D_drop` 最大的截面。
- 测量结束后，再使用左右最严重截面计算各角度的 `D_left` 和 `D_right`。

常规磨耗使用平均值反映整体情况，局部掉块使用最坏值避免严重缺陷被平均掉。

#### 节点 38：多组测量的最终打磨深度

每个角度最终计算：

```text
D_final = max(平均常规深度, D_left, D_right)
```

系统随后可以将 `D_final` 按每次 `0.05 mm` 换算为打磨次数，但打磨次数换算属于最终深度计算完成后的业务处理。
